### Что умею

- Разработка iOS приложений на **Swift / SwiftUI / UIKit**
- Архитектура: **MVVM-C, Coordinator, модульность (SPM)**
- **Swift Concurrency (strict)**: `async/await`, `Task`, `AsyncStream`, `actor`, `@MainActor`
- Real-time коммуникации: **WebSocket**, reconnect, heartbeat, throttling, single-flight
- Сетевой слой: **REST / JSON-RPC 2.0**, типобезопасные API клиенты
- Безопасность: **3DS 2.0, SCA, Keychain, Certificate Pinning, Face ID / Touch ID**
- AR/Computer Vision: **ARKit, LiDAR, RealityKit, Vision OCR, Core Image**
- Производительность: профилирование в **Instruments**, оптимизация рендеринга и сетевых запросов
- Тестирование: **XCTest**, Swift Testing, mock-first подход
