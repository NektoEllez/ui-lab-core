# SwiftUiViews

Практическая база переиспользуемых `SwiftUI` компонентов и экранов для рабочих задач.

## Что это
- Набор готовых UI-решений: кнопки, поля ввода, списки, баннеры, toast, навигация, шаблонные компоненты.
- Демонстрационные экраны для быстрого просмотра поведения и интеграции.
- Основа для дальнейшей оптимизации производительности, анимаций и архитектуры.

## Зачем
- Ускорять разработку продуктовых фич за счет проверенных компонентов.
- Держать единый стиль и предсказуемое поведение UI.
- Иметь место, где решения можно безопасно улучшать и масштабировать.

## Фокус развития
- Кроссплатформенная совместимость (`iOS` / `macOS` где уместно).
- Качество взаимодействий: доступность, анимации, обратная связь.
- Стабильность API компонентов и удобство повторного использования.

## Структура
- `SwiftUiViews/Components` — переиспользуемые UI-компоненты.
- `SwiftUiViews/Features/ComponentsDemo` — демо-экраны и каталог.
- `SwiftUiViews/Core` — общие стили, валидация, инфраструктурные helper'ы.

## Принцип работы
Каждое решение сначала появляется как рабочий компонент, затем проходит итерации оптимизации по читаемости, производительности и DX.
